# Fortis rolling PPL training log

The active prescription is the five-day rolling Push / Pull / Legs plan in `fortis-program.js` and `PPL_PROGRAM.md`. It replaces the four-core-session Fortis binder plan at the user's request. `fortis-program-legacy.js` preserves that 57-session plan and `fortis-program-ppl-v1.js`/`fortis-program-ppl-v2.js` preserve the earlier PPL prescriptions; `program_notes.md` and older changelog entries are historical context, not active instructions.

## Constraints

- Static HTML, vanilla ES modules, mobile first; GitHub Pages hosting. Keep `index.html` and `powerbuilding.html` byte-identical.
- Twelve calendar weeks, five scheduled sessions each week, sixty sessions total. Cycle Push A / Pull A / Legs A / Push B / Pull B / Legs B continuously; do not reset weekly. Suggested days: Mon / Tue / Thu / Fri / Sat. All six variants have ten scheduled appearances.
- Default main lifts throughout twelve weeks: Push A regular bench 3×4–6, Push B paused bench 3×6–8, Legs A back squat 3×4–6 and Legs B conventional floor deadlift 2×3–5. Push B also has seated DB shoulder press 3×8–12 (not standing barbell OHP) and cable fly 1×10–15. Optional SSB box squat/paused floor deadlift replace their lower main slot only via explicit pre-log session selection, with separate IDs/calibration. Advise sustained deliberate blocks, not random switches or automatic weeks 5–8 changes. Count actual SSB bar weight; stable box, braced contact, no rocking/relaxing.
- Deficit deadlift is not a default or app selector. It is only a separate coach/setup-checked low-deficit option with a stable full-foot platform and controlled position; do not silently log it under a programmed floor lift.
- Direct core: ab wheel 2×8–12, Push B cable crunch 2×10–15 at 2–3 RIR after the other work, and Pallof 2×10/side. Push B lateral raises are reduced to two sets; normal Push B total is thirteen work sets.
- All 60 sessions use normal work by default. Weeks 4/8/12 are recovery REVIEW points, not automatic deloads. An explicit pre-log lighter-session choice gives two main-lift sets, one per accessory, 4+ RIR. Lock prescription choices after logging starts. If several lifts decline over repeated exposures with poor recovery, advise roughly five next workouts lighter and reassess; a local stall needs a local adjustment. Five training days are the normal schedule.
- No plyometrics, explosive Olympic lifts, RDLs or front squats. Conventional deadlift is on Legs B. Current Fortis training was reported comfortable for knees/back; do not turn historical sensitivity notes into new diagnoses.
- Use the specified Fortis equipment and DB/cable substitutes. Leg extension is unconfirmed: retain default leg press unless the user confirms an actual machine, then permit an explicit pre-log replacement 2×10–15 with its own ID/load calibration; never assume availability or add extra sets. Do not assume incline/shoulder press machines, seated curls or standing calf machines exist. Equipment references: https://fortisfitness.ca/our-equipment/ and https://fortisfitness.ca/locations/fortis-fitness-east/ .
- Sixty-minute cap includes a scaled Wenning-inspired circuit, barbell ramps, rests and setup. Circuit plus ramps normally take 10–12 minutes. Lower-day unilateral curls take time; preserve main-lift rests and ALL quad/hamstring-curl work, trimming calves first when required and using efficient free stations. Do not guarantee an hour in a busy gym or shorten rests to force it.
- Main lifts: about 2 RIR and 3:00 rests; secondary bench 2–3 RIR. Pull-ups 2:30, other multi-joint presses/rows/pulldowns/leg press/belt squat 2:00, kneeling curl 1:30 after both sides, standalone isolation/core and complete accessory pairs 1:15. Accessories 2 RIR, cable crunch 2–3; no drops. Explicitly selected lighter sessions use 4+ RIR. Rest defaults are adjustable; preserve main-lift rests under the time cap.
- Circuit defaults: one easy round on every day at 8+ RIR and about 3–4/10 effort. A second upper round is optional only when useful, non-fatiguing and within the 10–12-minute preparation budget. Ramps must rehearse the actual paused/SSB/box variation. Circuit sets do not count as hard work sets. They do not replace main-lift ramps or supply missing hard-set muscle volume.
- Calibrate every lift manually. `fortis-loads.js` may show explicitly labelled low/very-low-confidence first-trial hints sourced from historical binder prescriptions or generic coaching guesses. Hints are not confirmed current strength; explicit application changes only a session target, never actuals. Ambiguous machine variants require manual entry after checking their loading convention. Normal hints must not silently carry into selected lighter sessions; only bodyweight has a numeric zero default there. Prescriptions and performed sets remain separate.
- Progression suggestions inspect the latest prior normal exposure with any records for the same exercise/variation: incomplete work, missing actuals/RIR or missed effort targets block an increase. All prescribed sets must reach the rep ceiling at the intended effort to suggest the smallest practical increment and return to minimum reps. Machine/seat/grip/range continuity requires user checking. Never automatically write weights, advance by calendar date, infer success from checkmarks, or reinterpret blank loads as zero.
- `fortis-timer.js` owns exact m:ss rest state in account-scoped per-tab sessionStorage. Keep start manual for unilateral/pair work. Preserve running/paused mode when adding time, restore on reload, retain a completed display, and label its source exercise/session. Finishing only its source session clears that timer. Custom rest supports 15–900 seconds; background alerts are not guaranteed. Keep the existing load/timer rules in `ppl-v3`, and never rewrite older logged records.
- `fortis-session.js` rebuilds account-scoped choices and freezes them before the first target, actual entry or completion. Frozen prescription settings take precedence over later setup edits; reject writes from a stale displayed setup. Lock choices using all session record IDs, including other variants, rather than only visible exercises.
- Preserve legacy logs as read-only History. Keep storage/auth code and the existing `fortis-v1` account isolation unchanged. New record IDs must use `ppl-v3`; preserve `ppl-v1` and `ppl-v2` history via their archives and keep PPL view selection separate from binder state. Main-lift IDs must include the variation slug so LAST comparisons cannot cross different variations. Never remap old records to new exercises or silently migrate logged loads.
- No sleep, bodyweight or session-note inputs. Workout data and credentials must not be committed to GitHub.
- Only public project configuration belongs in `fortis-config.js`; never expose a secret/service-role key. No cloud project is provisioned here; live Auth/policy/cross-device checks are required after setup.
- `npm test` must pass. Review mobile layout and persistence after relevant interface changes. Preserve meaningful legacy verification alongside new-program checks; do not rewrite the PDF-derived fixture to make a new prescription appear original.
